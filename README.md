# PyNotes

A searchable Python reference for coding practice, inspired by personal Python notes. Browse topics, copy examples, and save useful notes in your browser.
Website URL : https://waseem2502.github.io/Python-guide-/ 
 
## Run locally

Open `index.html` in a browser. No installation or server is required. Fonts and icons are loaded from external services and require an internet connection. Saved notes are stored in the browser on the current device.

## Publish on GitHub

1. Sign in to GitHub and create a new **public** repository.
2. On the repository page, choose **Add file > Upload files**. Upload `index.html`, `style.css`, `app.js`, and `README.md`, then commit the files.
3. To publish the site, open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Once deployment finishes, the Pages settings will show the website URL. The public repository URL is separate from the website URL.
